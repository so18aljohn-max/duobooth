# DuoBooth

A portable browser photobooth for solo and long-distance photo sessions.

## Features
- Solo or two-device synchronized camera sessions
- Six-shot booth flow
- Select four favorites
- 9 export layouts: classic 4-cut, double strip, Polaroid, 2x2 grid, film sprocket, Story 9:16, wide collage, postcard, square social
- 10 filters with adjustable intensity
- Custom frame colors, captions, and spacing
- Photo-library import
- Native share when supported
- Installable PWA shell
- Local style memory
- Peer-to-peer live camera connection via WebRTC/PeerJS

## Privacy
Captured photos stay in the browser unless the user downloads or shares them. Live camera media is peer-to-peer where WebRTC permits it.
